# 📒 Address Book Management System

A menu-driven **Address Book Management System developed in C** to manage contact information efficiently.

### ✨ Features
- Add, search, edit & delete contacts
- Display and sort contacts
- Duplicate contact checking
- Input validation
- File handling for data storage

### 🛠️ Technologies
- C Programming
- Structures & Pointers
- File Handling
- Dynamic Memory Allocation
